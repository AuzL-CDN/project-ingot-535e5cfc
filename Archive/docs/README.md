## 🎯 Common Tasks

### I want to...

2. Follow [SharePoint Deployment Guide (Non-Technical)](SharePoint-Deployment-Guide-NonTechnical.md)
3. Use [Migration Verification Checklist](Migration-Verification-Checklist.md) to verify

#### Migrate from Supabase to SharePoint
1. Read [SharePoint Technical Migration Guide](SharePoint-Technical-Migration-Guide.md)
2. Follow [M365 Implementation Guide](M365-Implementation-Guide.md)
3. Complete [Migration Verification Checklist](Migration-Verification-Checklist.md)

#### Set up GitHub integration and CI/CD
1. Follow [GitHub Deployment Workflow](GitHub-Deployment-Workflow.md)
2. Configure GitHub Actions as described
3. Set up Azure Static Web Apps deployment

#### Configure Word templates
1. Read [Word Templates README](word-templates/README-Templates.md)
2. Review [Document Automation Flowchart](Document-Automation-Flowchart.md)
3. Upload templates as per [SharePoint Deployment Guide](SharePoint-Deployment-Guide-NonTechnical.md)

#### Understand system features
1. Read [Application Documentation](APPLICATION-DOCUMENTATION.md)
2. Review [System Requirements](SYSTEM-REQUIREMENTS.md)
3. Check main [README.md](../README.md) for overview

#### Troubleshoot issues
1. Check troubleshooting section in [Application Documentation](APPLICATION-DOCUMENTATION.md)
2. Review [M365 Implementation Guide](M365-Implementation-Guide.md) troubleshooting
3. Use [Migration Verification Checklist](Migration-Verification-Checklist.md) to identify issues

All documents include version numbers and last updated dates at the bottom.

- Descriptive names with title case
- Hyphens for multi-word names

- **Quick Start Checklist**: After each major release
- **Technical Guides**: When architecture changes
- **Deployment Guides**: When process changes

## 🆘 Getting Help

### Support Resources

**Technical Support**:
- Check the relevant documentation first
- Review troubleshooting sections
- Contact your IT support team

**Business Questions**:
- Refer to [Application Documentation](APPLICATION-DOCUMENTATION.md)
- Contact project stakeholders
- Review feature descriptions

**Deployment Issues**:
- Use [Migration Verification Checklist](Migration-Verification-Checklist.md)
- Check [SharePoint Deployment Guide](SharePoint-Deployment-Guide-NonTechnical.md)
- Contact your SharePoint administrator

### Reporting Documentation Issues

If you find errors or outdated information:
1. Note the document name and section
2. Describe the issue clearly
3. Suggest corrections if possible
4. Contact the documentation maintainer

## 📝 Contributing to Documentation

### Documentation Guidelines
- Use clear, simple language
- Include examples where helpful
- Add screenshots for complex steps
- Keep formatting consistent
- Update version numbers and dates

### Updating Existing Documentation
1. Make changes in your branch
2. Update "Last Updated" date
3. Increment version number if major changes
4. Create pull request with description
5. Request review from technical lead
